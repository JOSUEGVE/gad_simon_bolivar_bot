# GAD Simón Bolívar - Automatización de Trámites

Sistema para la gestión y validación automática de trámites ciudadanos para el GAD de Simón Bolívar.

## Características
- Validación de cédulas ecuatorianas (10 dígitos).
- Registro persistente en formato JSON.
- Suite de pruebas unitarias con Pytest.

## Instalación
1. Clonar el repositorio.
2. Crear entorno virtual: `python -m venv .venv`
3. Activar entorno: `.\.venv\Scripts\Activate.ps1`
4. Ejecutar pruebas: `python -m pytest`
